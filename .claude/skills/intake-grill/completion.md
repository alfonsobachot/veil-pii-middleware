# Done When — Full Criteria

The grill is complete only when all five conditions hold. A waived condition
must be recorded as an assumption in the `## Intake Grill` table.

1. The user's desired outcome is unambiguous — not "improve performance"
   but "response time under 200ms at the 95th percentile."
2. At least one testable acceptance criterion exists — observable, binary,
   not "it feels fast."
3. Risk class is explicitly named (low / medium / high) — not taken from
   the template default without discussion.
4. Execution lane is deliberately chosen — not left at
   `agent-with-checkpoint` default without consideration.
5. Domain-specific edge cases or integration risks have been surfaced —
   even if resolved as out-of-scope.
